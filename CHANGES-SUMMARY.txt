7. PROCHAINES ÉTAPES (POUR L'UTILISATEUR)
================================================================================

1. npm install (si pas déjà fait)
   cd backend && npm install

2. Configuration .env
   cd backend && cp .env.example .env
   Remplir : MONGODB_URI, JWT_SECRET, BREVO_API_KEY, etc.

3. Test local
   npm start
   Accéder à localhost:5000
   Vérifier /robots.txt et /sitemap.xml

4. Déploiement
   Push vers GitHub
   Connecter à Render/Railway/Fly.io
   Ajouter variables d'environnement
   Déclencher déploiement

5. Google Search Console
   Ajouter domaine : https://yaka-marche.xyz
   Soumettre sitemap : https://yaka-marche.xyz/sitemap.xml
   Monitorer indexation
